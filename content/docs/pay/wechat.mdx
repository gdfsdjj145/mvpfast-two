title: 微信支付
description: 微信支付接入与通知配置
---

MVPFast 直接在 Next.js 服务端调用微信支付 APIv3。支付下单时的 `notify_url` 指向当前站点的 `/api/wechat-pay-callback`，无需微信云托管。

在 Vercel 的 Production 环境配置商户号、商户 API 证书、APIv3 密钥，以及微信支付公钥（或平台证书）和对应 ID/序列号：

```text
WECHAT_MCHID=商户号
WECHAT_SERIAL_NO=商户 API 证书序列号
WECHAT_PRIVATE_KEY=商户 API 私钥 PEM
WECHAT_API_V3_KEY=商户 APIv3 密钥
WECHAT_PAY_VERIFY_KEY=微信支付公钥 PEM 或微信支付平台证书 PEM
WECHAT_PAY_VERIFY_SERIAL=PUB_KEY_ID_... 或平台证书序列号
NEXT_PUBLIC_SITE_URL=https://www.mvpfast.top
```

商户私钥用于发起支付请求；微信支付公钥或平台证书用于校验微信发来的通知，两者不可互换。与商户私钥配套的 `BEGIN CERTIFICATE` 商户 API 证书也不能用于通知验签。服务端会先按请求原文验签，再解密和核对商户号、AppID、币种与支付状态。验签失败时返回非 2xx，让微信按其通知机制重试。

当前购买页面仍通过服务端查询微信订单状态，并在确认成功后创建业务订单。通知接口负责可信接收，不会单独发放商品或积分。需要自动履约时，应增加服务端待支付订单与幂等处理。

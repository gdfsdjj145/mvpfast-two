目前支持 PC 和 H5 的微信登录方式，使用微信授权登录。

##### 配置

```json
NEXT_PUBLIC_WECHAT_OPEN_APPID=""
WECHAT_OPEN_APPID=""
WECHAT_OPEN_APPSECRET=""
NEXT_PUBLIC_WECHAT_APPID=""
WECHAT_MP_APPSECRET=""
```

移动端还需在公众号后台将站点域名配置为网页授权域名。AppSecret 只放在 Vercel 服务端环境变量中；公众号网页授权由当前项目处理，无需单独部署云托管服务。
